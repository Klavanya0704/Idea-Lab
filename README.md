# Smile Design Studio

Build a premium, modern dental hospital website that closely reproduces the attached reference image.

IMPORTANT:
Treat the attached image as the PRIMARY visual reference. Do not redesign it into a generic dental website. Recreate the same overall composition, proportions, visual hierarchy, color palette, typography style, card shapes, gradients, spacing, imagery placement, and premium aesthetic shown in the reference.

Website name:
SmileCare Dental Hospital

==================================================

1. OVERALL DESIGN DIRECTION
   \==================================================

Create a high-end, modern dental hospital landing page with a clean medical + luxury aesthetic.

The design should feel:

- Premium
- Professional
- Trustworthy
- Friendly
- Modern
- Bright
- Soft and elegant
- Healthcare-focused without looking clinical

Use generous white space, rounded corners, subtle shadows, glassmorphism effects, soft gradients, and high-quality dental photography.

The page should look VERY close to the attached screenshot.

Do NOT use:

- Dark themes
- Generic Bootstrap-looking components
- Excessive borders
- Flat/basic cards
- Generic stock dashboard styling
- Heavy shadows
- Random colors
- Different page structure

================================================== 13. UI DETAILS
==================================================

Use:

- Border radius: 20–32px for major sections
- Cards: 18–24px
- Buttons: pill-shaped
- Soft shadows
- Thin subtle borders
- Glassmorphism where appropriate
- Smooth hover animations
- Micro-interactions
- Smooth scrolling
- Gentle fade/slide animations

Buttons should have:

- Hover scale around 1.02–1.04
- Smooth transition
- Arrow movement on hover

Cards:

- Slight lift on hover
- Soft shadow increase
- No aggressive animations
